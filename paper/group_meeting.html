01 · Problem

默认管线为什么浪费

交互模式

  • UAV 低空感知 + 地面自然语言提问
  • 典型答案器：边缘 Vision–Language Model (VLM)
  • 默认：上传整图 → 跑一遍 VLM

代价（测量结论）

  • UAV 电池与空口带宽都紧
  • 边缘 VLM 前向是环路里最耗能的一步
  • 在我们测的每个链路上：VLM 焦耳 > 传图焦耳
  • 许多问题根本不需要整图

现有语义/任务导向通信的两个隐含假设

① 图像（或潜表示）≈ 准确率上界

更便宜表示只被当成「用准确率换时延」；本文表明对符号推理题，token 比图更准。

② 发端–收端联合训练

绑定单一推理后端；本文用任务无关发端 + 冻结商用 VLM，结果可迁移。

04 · Routing

三种发射端选择器（无需 CSI 做 level 决策）

① Wilson-LCB 校准 LUT

按（题型, SNR…）单元估计准确率下界，取 argmax LCB。
训练折拟合，测试折报告。

② 零参数语义规则

symbolic → s₁ (token) counting / comparison co-presence / threshold perception (presence) → s₂ (image)

与 LCB 选择器统计不可区分（主集 McNemar p=0.12；AWGN 上 bit 一致）。

③ 逐样本预测器

发送端特征上的 logistic：+0.7–1.1 pt，载荷近乎减半。接收端 VLM 口头置信度反校准（AUC 0.406），不能用来路由。

维度消融：题型是唯一承重路由维；再叠 SNR/视角/新鲜度/风险，池化准确率变化 ≤ ±0.003。
05 · Complementarity

证据–问题互补性（核心现象）

符号推理题 · 更爱 token

  • counting / comparison / co-presence
  • 相对传图：准确率 +0.11 ~ +0.17
  • token 保留离散计数充分统计

感知题 · 更爱 image

  • presence
  • 相对 token：图更好（约 −0.08 若用 token）
  • 需要存在性 / 外观召回

边界类型

threshold：符号跨数据集变号 → 规则里仍归 symbolic 支，但分析上标为边界。

谁解码 token？

必须符号解码。把同样 token 当文本塞给 VLM ≈ −15 pt。不是「同一后端吃不同表示」，而是证据管线互补。

08 · Energy

能量：计算主导的 Pareto 前沿

实测 GPU 功率（边缘代理 RTX 4060）

阶段功率增量焦耳量级
Idle~52 W—
YOLOv8n (s₁)~59 W~0.07 J 量级
Qwen2-VL-2B (s₂)~108 W~32 J 量级

在测试的每个链路上：VLM 焦耳 > 无线电焦耳 → 最大杠杆是「能不跑 VLM 就不跑」。

每答案能量–准确率

  • 类型感知路由相对 rate-adaptive 图：2.2× 更省焦耳且更准（各 SNR 比约 2.23–2.25）
  • 固定 token：比图便宜 75–79×（比路由再便宜 33–35×）
  • 能量价格 λ 扫过逐样本预测器 → 在 all-token 与 accuracy-first 之间可控
  • 条件 Pareto 占优命题形式化该效应
绿色叙事：效率来自 evidence frugality，而不仅是更好的源/信道编码；与现有功率/带宽分配器可组合，而非竞争。
09 · Findings

三个反直觉发现

① Error-free 仍输路由

无信道错误的全图传输准确率仍低于路由 → 问题在证据种类，不在衰落。

② 计算主导

每答案前沿由 VLM 计算主导；发射功率/速率适配是次级杠杆。

③ Less is more

按置信度 top-t 截断 token：threshold 题 +7.7 pt——滤假阳性，非单调「越传越多越好」。

其他可汇报细节

固定码率 token 有 cliff；信息中断自适应更稳 DJSCC 紧凑学习基线纳入银行 第二数据集规则仍与 selector 不可分 跨 VLM 扩展见 future work
10 · Theory (brief)

理论与命题（组会一分钟版）

为什么规则有效

  • 理想极限下：token 是离散计数问题的充分统计
  • 图像保留存在性/外观信息
  • 条件引理解释「何时 token 优于 image」的方向性

能量–准确率 Pareto

  • 条件 Pareto-dominance 命题：类型感知路由在联合焦耳轴上占优固定图像管线
  • 实验 margin 实例化该命题（2.2× + 更高准确率）
  • λ 作为每答案能量预算对偶，可与 slot 级资源分配器对接
诚实边界：token 有限块长下气口计费略偏乐观（文中已量化上界）；DJSCC 是紧凑对照而非 SOTA codec；s₃ 不进主表。
11 · Positioning

在 TGCN 绿色语义通信线中的位置

Cover letter 口径（3 句）

  1. 现有 TGCN 绿色语义工作优化固定语义表示的能量（功率、带宽、RSMA…）。
  2. 本文转向测量：任务究竟需要哪一种表示，并在真实冻结 VLM + 编码链路上报端到端准确率与实测通信+计算焦耳。
  3. 结论可执行：前沿计算主导 → 题型条件路由在每 SNR 上 2.2× 降焦耳且升准确率，与现有分配器可组合。

我们卖什么

Evidence-level 路由 · 互补性 · 统一 channel-use+joule 方法学 · 绿色杠杆在「拒跑 VLM」。

我们不卖什么

不是新 SOTA JSCC；不是端到端可微 codec；不是 RL 资源分配主文（那是另一条线）。
