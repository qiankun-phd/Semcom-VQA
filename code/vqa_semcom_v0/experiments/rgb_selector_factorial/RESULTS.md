# EXP-013：四组选择器对照结果

2026-09-22 完成。**有局部改善，但四组均未通过预先约定的系统筛选，不能宣布联合路由已经有效。** 本轮到此交付，不新增训练、不解封测试、不改论文。

## 做了什么

只复用 EXP-012 的 TDIUC/COCO 特征和九档答案缓存：480图训练、120图内部验证、已使用过的历史开发120图。四组为输入原尺度/图像块除以sqrt(83)，交叉绝对正确率BCE/相对2k-low的带符号增益MSE。网络均为339→128→64→9，种子7/17/27。增益包含−1误伤，不只是“救回”的正例。

12个小型MLP已在服务器CPU完成拟合，训练及导出流程约4.93秒；此前数据生成、编码和VLM成本不包含在此时间内。基础编解码器、Qwen及LoRA全部冻结，没有新的图像推理。所有检查点冻结后才开展旧开发标签评分。

绝对原尺度组的25920个评分与原模型最大差0，2880次选档完全一致。独立审计核验41个源文件和17个冻结文件哈希不变，并复算564项结果，零差异。

## 说明什么

1. 原尺度增益组在两集各多对2题，但平均字节由约2.1k升至约3.0k。内部验证仍比学习式码率单轴少对1题，字节也略多；历史开发在相近字节下仍少对1题，且两集接收token更多。尚未形成超出强单轴的联合选择优势。
2. 尺度均衡不能作为已验证的修复：绝对正确率组在内部验证少对3题、历史开发多对3题。两集的尺度AUC主效应分别−0.0423/+0.0958；目标/损失主效应+0.0617/−0.0444，方向反转。
3. 12项探索性对比经过统一Holm校正后均不显著，最小p=0.1044。逐项95%bootstrap区间未做多重校正；个别区间不跨0不等于校正后显著。AUC实际仅20/23张mixed图有信息，不显著也不能证明所有尺度或增益学习方案无效。
4. 所有组均未过原EXP-012门槛，完整成本门槛仍PENDING。即使历史开发某个单种子达到93题，也不能挑出它替代三种子集成主结果。

两个开发集已反复查看，不能称独立测试。目标因素同时改变参数化、损失及检查点准则；尺度因素也改变优化/正则化几何。结论是当前输入、样本和训练配方仍不足以证明实用的联合选档收益，不是整个语义通信方向被否定，也不是确定了唯一失败原因。

## 后续边界

停止为这版低成本统计特征选择器自动加轮次、换种子或扫资源惩罚。保留普通神经重建、固定配置和学习式单轴对照作为研究候选；如继续联合选择，需要先给出有明确新增信息/机制的下一轮方案。独立测试、SNR和能耗必须另行冻结对照后授权，不由本报告自动启动。
