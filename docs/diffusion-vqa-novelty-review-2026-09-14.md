# 扩散重建驱动的语义通信与 VQA：初步创新性调研

调研日期：2026-09-14。范围：公开论文检索及关键论文 HTML 正文核查；不是穷尽性系统综述。没有启动训练或修改现有论文与实验。

## 结论

候选流程：图像 → 可学习语义编码器 → 无线信道 → 扩散图像重建 → VQA。

基础模块及其大部分组合已有先例，单纯串联流程、换成扩散解码器、加入问题条件或问答损失，创新性不足。尚不能断言完全同构且以最终 VQA 真值监督联合训练的方案已经存在，但也不能据此声称首次。

建议探索的具体问题：在给定通信与接收计算预算下，如何控制扩散重建引入的回答错误，尤其是计数、小目标和空间关系错误。该方向的创新性仍需以具体机制与实验确认。

## 关键论文与重合边界

| --- | --- | --- |
| [MU-DeepSC, 2021 预印本](https://arxiv.org/abs/2108.07357) | 联合设计语义收发机，直接从接收语义完成 VQA | 端到端语义通信与 VQA 已有；必须比较不重建图像的路径 |
| [GESCO, 2023 预印本](https://arxiv.org/abs/2306.04321) | 传输压缩语义，接收端用扩散生成场景 | 扩散作为语义接收端不是新概念 |
| [SD-GSC, 2024 预印本](https://arxiv.org/html/2408.00428v2) | 语义自编码器、扩散去信道噪声；分阶段训练后整体微调 | 端到端训练本身不能作为区别；其重点为图像重建 |
| [Chen 等，水下图像语义通信，2024 预印本](https://arxiv.org/html/2408.12616v2) | 用户问题驱动语义提取；发送答案文本、关键图像区域和压缩全图；双 ControlNet 引导扩散恢复 | 问题条件、局部保护、问答监督与扩散组合已经出现；问答损失位于发送侧，不能直接等同于接收端重建后 VQA 监督 |
| [QO-ISC, 2026 预印本](https://arxiv.org/html/2607.28276v1) | 问题引导图像编码与重建；用 LLaVA 查询条件特征损失训练；用 BLIP-2 比较原图和重建图的答案 | 最接近的任务逻辑。其自身使用非扩散重建，但对比了上述扩散方案；答案一致性不等于真值准确率 |
| [MTGC, 2025 v1](https://arxiv.org/html/2512.06344v1) | 文本、压缩图像和任务相关语义共同引导扩散，以减少语义偏差 | 多模态引导、语义保真、减少幻觉均已有研究；该版本不是接收端 VQA 工作。arXiv 当前页面标题已改为 SDGIC，引用须区分版本 |
| [Schrödinger Bridge GSC, 2026 预印本](https://arxiv.org/abs/2604.17802) | 以更直接的生成运输过程降低幻觉和计算开销 | 不能把“降低生成幻觉与采样成本”作为全新问题 |

### 最接近论文的实质区别

QO-ISC III 节的用户意图损失比较原图与重建图在相同问题下的多模态隐状态；VI 节用另一个模型 BLIP-2 评估答案匹配。不能将其误写成直接用答案真值交叉熵训练，也不能说其没有跨模型评估。该论文已经展示图像质量与答案保持之间的差异。

水下方案 II-D 节使用发送端问答损失和区域定位损失训练语义编码，扩散端学习噪声预测。算法发送模型预测答案，而非仅发送视觉特征。因此，如果我们的设定把重计算放在边缘接收端，应保留这一系统区别；同时加入“发送端回答后只传答案”的成本基线。

## 可研究但尚未验证的机制

### 1. 面向回答风险的证据保护

学习在固定载荷内分配“全局潜变量”和“关键视觉残差”：优先保留会改变真实答案的区域或对象信息。扩散负责恢复其余部分。训练时考虑信道噪声与生成随机性，而非只优化平均图像质量。

潜在目标：最小化 VQA 真值损失，并满足传输符号数、接收计算时间和关键对象错误约束。单纯加权相加多个常见损失并不构成充分贡献，需要明确保护策略如何随问题、信道与生成不确定性变化。

已存在局部 ControlNet 和多模态条件机制，故必须对比同载荷的 ROI 编码、区域引导扩散和问题引导非扩散重建。

### 2. 生成不确定性驱动的补传或停止

多次采样所得图像可能视觉不同，但答案相同；也可能只改变一个小物体就导致答案改变。可研究按回答分歧选择少量补充证据，或决定是否值得继续扩散。

这是候选机制，不是已验证创新。多样本一致不保证真实正确；共同偏差可能产生一致错误。补传必须计入上行载荷、反馈、往返时延，且需要与直接基于 VLM 不确定性的 ROI 补传比较。在线控制不能获得测试真值或原图答案。

## 必须回答的技术问题

1. **为何必须重建图像？** 对固定接收语义 y 和问题 q，若生成随机数不含额外场景信息，重建图像是 y、q 的后处理，不能凭空增加当前场景的证据。实践收益可能来自预训练图像 VQA 模型的兼容性及先验利用，需要实验证明。
2. **发送端何时知道问题？** 已知问题时可做查询编码，但也须比较本地回答后传答案；问题只在接收端出现时，编码器不能偷偷访问问题。未知未来问题、多次问答的复用场景可研究，但也不能预先声称新颖。
3. **什么叫端到端？** 只有最终任务损失通过重建与信道影响发送端参数，才是任务层面的联合优化。模块串联部署或各自训练不能代替这一点。固定 VQA 权重仍可传播输入梯度，黑盒 API 则需要代理模型或其他训练方法。
4. **幻觉如何测量？** 同时报告真实 VQA 准确率、原图回答一致率，以及对象增删、数量和空间关系改变。不能只用 FID、CLIP 相似度或模型自信度。
5. **能耗收益来自哪里？** 当前稿件核算 UAV 与边缘端成本。新方案应分别报告编码、发送、扩散和 VQA 开销。传输减少不自动意味着总能耗降低。

## 最小验证协议建议

先固定 VQA 接收器和现有数据划分，进行独立小样本实验。建议约 300–500 张测试图，每图覆盖存在性、数量、属性和关系问题，并报告不确定区间；该规模仅用于筛查趋势。

必要比较：

- 原图 → VQA：参考性能，不是绝对上界。
- 传统压缩加信道编码 → VQA。
- 学习型非扩散重建 → 同一 VQA。
- 相同视觉条件及预算 → 扩散恢复 → 同一 VQA。
- 直接语义特征 → VQA：匹配任务模型能力与训练数据，说明体系差异。
- 问题引导非扩散编码、ROI 方案，以及条件允许时复现最接近的扩散基线。

在相同带宽/信道使用次数和发射功率下比较，所有文本、区域、潜变量、元数据均计入载荷。数字与模拟方法应使用可比较的资源口径，不能直接把潜变量维度当作比特数。

扩散方案使用多个随机种子，记录 VQA 准确率和回答翻转、每个问题类型的退化、端到端时延及分端能耗。计算采样步数与重复采样带来的额外成本。

若只有视觉质量提升而 VQA 无收益，不支持以 VQA 性能为主线；若低码率下 VQA 明显改善但总能耗增加，应准确定位为带宽换计算。只有证据保护机制在强基线和合理成本约束下带来可靠收益，才值得投入完整训练。

## 与当前项目的衔接

现有工作区主线是问题条件下的证据路由，以及符号回答与冻结 VLM 两条处理路径。建议把扩散方案作为独立候选路线先验证，不因换用生成模型直接推翻现有实验。训练接口、问答数据、信道配置和能耗核算需另行审计，当前调研没有验证它们已适配扩散训练。
