## 解决的问题

1. **学习型路由漏计检测成本。** 在历史记录指向的 lab-s1 上，只读核验 /home/qiankun/phd_research/w5_persample_energy/scripts/w14_mlp_10seeds.py：第 94–95 行仅检测分支包含 E_DET，第 106 行按分支求和。W5 线性路由和 W11 价格扫描具有相同口径。MLP 和线性路由在所有查询上先运行检测器，因此既有策略的修正为 E_new = E_old + f_img × 0.4275 J。保持原有选择和准确率不变。
2. **类型规则和两个 LUT 记录混用。** comparison_v3_5qt.csv 的 M4 与 paper1_stats.json 中用于 TOST 的记录策略并非同一 LUT。现在直接聚合配对预测得到免训练类型规则，并回放统计报告中的既有 LUT 选择；没有重新拟合 LUT。AWGN 两者一致，低信噪比衰落信道下并不一致。
3. **统计对象混用。** 十种子主实验采用均值及最小—最大范围；三种子消融采用现有标准差；按图像聚类的 bootstrap 区间保留其三种子来源，不挂接到十种子均值上。
4. **比较任务集合不同。** 模拟语义基线的两类问题结果放入补充材料，其他方法也按相同两类问题展示；不与五类问题的总体准确率直接排序。
5. **系统节能与机载节能混淆。** 分开展示总核算能耗与机载检测加无线传输能耗；明确减少边缘 VLM 调用不等于同比降低无人机电池消耗。
6. **敏感性叙述超出记录。** 带宽/功放效率图仅重新计算既有负载的通信成本；问题构成图仅重新加权已有三种子分类结果。均不表述成新信道试验或重新训练。

- 实际类型规则的核算节能约 55.44%–55.49%，不再借用旧 M4 列描述类型规则。
