1. 系统总览

无人机拍摄低空图像，针对每个视觉问题（VQA task），在多个语义服务等级之间选择以何种形式把信息传到边缘节点；边缘用视觉语言模型 Qwen2-VL 作答；一个强化学习控制器在通信/计算/缓存资源约束下决策"传什么、传多少、给多少资源"，最大化任务成功率。

核心思想：通信目标不是 bit/像素级保真，而是 VQA 答案正确率。低 SNR / 简单问题用轻量语义证据（detector token），高 SNR / 复杂问题才付代价传图像。

① 语义质量模型 (LUT)
把"某条件下某服务能达到的正确率"建成可查询函数，供 RL 在线决策，不必每步真跑 VLM。
② 通信信道模型
SNR 经链路自适应 → 可达速率 → 字节预算 → 图像质量，决定语义证据退化程度。
③ RL 资源分配
two-timescale PPO + Lyapunov 队列，决策服务等级、带宽/功率/算力、UAV 机动。
④ 接收端
真实 VLM (Qwen2-VL-2B) 作 answer reasoner，比 logic-based 更 AI-native。

4. 语义质量模型 (LUT)

A_k = LUT[ question_type, service_level, snr_bin, view_quality_bin, freshness_bin, risk_level ]
取值 = accuracy 的置信下界 LCB (Wilson 二项区间)
  • 离线构造：枚举各条件格，用真实 Qwen/detector 跑经验正确率(1/0) → 聚合 mean / ci_low / lcb / uncertainty / payload。文件 scripts/run_v1_detector_eval.py、semantic/utility.py。
  • SNR 单调校准：calibrate_snr_monotonicity 强制正确率随 SNR 单调不降。
  • 在线接口：U_sem(...) 查表（缺格最近邻回退 _nearest_snr_cell）；RL 用 get_service_candidates(obs) 拿每个候选服务的 accuracy_lcb / semantic_feasible / deadline_feasible / joint_feasible。
  • 演进：V0 规则 → V1 mock → 真实 Qwen → detector 证据 → V1.6/1.7/1.8 校准 → V1.9 SNR 校准。当前 outputs/lut/v1_9_semantic_utility_with_ci.csv（648 格，16 万样本）。
参数化效用模型（探索）：parametric_utility.py 用贝叶斯逻辑回归(IRLS+Laplace+过散度+残差方差)拟合 LUT。诚实负结果：完整低噪声网格上离散表点精度仍更优（表=记忆）；参数化价值在校准不确定性 + 离格插值 + 压缩（LCB coverage≈0.95），不在点精度。

5. 通信信道模型 (v2.0 链路自适应)

物理依据：真实通信传图像用链路自适应(AMC)+ARQ，把工作点维持在阈值以上 → 图像近乎无损；SNR 决定可达速率，速率在带宽/时延预算下决定能传多少字节(压缩质量)。误码可见损坏只是深衰落 outage 的例外。

可达速率   R(SNR) = B · E[ log2(1 + SNR·|h|²) ]
字节预算   budget = R · τ / 8          (τ = 每图传输时隙)
图像编码   在 budget 内搜最高 JPEG 质量/分辨率 → 真实 cv2 编解码 → 喂 Qwen
深衰落中断 P_out = P( log2(1+SNR·|h|²) < r_min ),  r_min=(min_payload·8/τ)/B

token 路 (s1) 全 SNR 鲁棒：payload ~256B → r_min≈0.0068 b/s/Hz → outage≈0（-5dB 仅 0.16%）→ token 几乎不丢，精度由 detector 决定，与 SNR 无关。这正是语义通信的核心优势。

Qwen2-VL-2B-Instruct（本地 4.2G，RTX 3080）。build_vlm_prompt(task, evidence_text)：s1 喂结构化 token 文本，s2/s3 喂退化图像。presence→yes/no；counting→整数（默认取 detector_target_count 除非 token 否定）。

8. 强化学习资源分配

  • 框架：DI-engine，集中式训练+执行。主算法：Two-timescale mobility-aware semantic PPO（语义路径 + UAV 机动 双时间尺度）。
  • 机制：Lyapunov admission / resource projection、deadline-aware evidence guard、infeasibility-aware reject。
  • 动作：service_level(cache/token/image/ROI/reject) + bandwidth + power + cpu_share + gpu_share + UAV assignment/机动。
  • 奖励：semantic utility(A_k≥ε_k 成功) − 时延/能耗惩罚 − 队列/风险欠账。
  • 卡点：low_snr_blockage 场景 deadline violation ~0.854，环境侧诊断中。

11. 与研究方向对标 (定位)

对齐主流：task-oriented、传 detector 语义证据而非像素、VLM 作接收端、SNR/信道自适应、多级自适应——契合 Liu 2411.02452 (wireless VQA)、UAV cognitive semcom (2502.03761)、2025 VLM-receiver 趋势。

诚实定位：s2 图像路当前是"速率自适应 JPEG"（经典分离信源信道编码），不是领域定义的"学习式语义图像编码 (DeepJSCC/VQ)"。建议把 s2 定位成"传统高保真服务/资源分配的另一极"，创新押在 RL 资源分配 + 语义效用 LUT + token 语义服务（契合 RL 主线）；若要图像路也语义化，需另接 DeepJSCC/VQ 学习式 codec。
