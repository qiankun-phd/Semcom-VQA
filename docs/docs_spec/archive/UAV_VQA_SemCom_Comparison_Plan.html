2. 公平对比协议（审稿人最先攻击的点）

三条铁律保证准确率差异 100% 归因于通信方案：

  • 同后端：所有方法统一用 Qwen2-VL-2B 作答（s1 直解码路语义来自同一检测器）。
  • 同信道：同一衰落实现（E[|h|²]=1）、同 SNR 点、同种子（seed=23）。
  • 同预算：同字节/时延预算 τ（tx_time_budget_s=0.3, bandwidth_hz=1e6）。
  • 同数据：VisDrone-DET val 548 图 → presence+counting（v1_7_tasks.csv），同一任务列表。
  • 同评分：presence 精确匹配；counting 用 count_tolerance_ratio=0.1 容差；归一化规则统一。

M2 实现选项（A 阶段拍板，唯一需新写的基线）
DeepSC 精髓 = 模拟传输 + 无数字编码 → 换"无悬崖、优雅降级"。在 Qwen(吃像素)后端下三选一：
  • M2a 最忠实(成本高)：训轻量 JSCC 自编码器(image→feat→加噪→重建)→Qwen。≈DeepJSCC，要训练。
  • M2b 折中(推荐)：JPEG 后 DCT/像素系数当模拟符号过信道(功率归一+复高斯，无 LDPC)→重建→Qwen。经典 uncoded analog，无需训练，干净体现"数字 vs 模拟"对照。
  • M2c 最轻：检测特征(bbox/置信)上加模拟噪声→语义解码器。仅 token 路模拟对照。
推荐 M2b：无训练、忠实体现 DeepSC 卖点、与 M1 形成最干净对照；M2a 留作 reviewer 追问的升级选项。

4. 评价指标（对齐 GO-SG / MU-DeepSC / How-to-Evaluate）

4.1 任务准确率（主）

总体 accuracy；按问题类型拆分(presence/counting)；95% Wilson 置信区间 + 多种子。

4.2 传输代价（目标导向核心）

  • payload bytes / query（已有 payload_bytes）
  • CBR = 信道符号数 / 源维度，符号数 = payload_bits / bits_per_symbol（DeepJSCC 归一约定）
  • 端到端时延：t = payload_bits/(B·log₂(1+SNR·|h|²)) + t_detector + t_vlm（GO-SG latency 分解）

4.3 鲁棒性

准确率随 SNR 下降的斜率（越平越好 → 量化 cliff-effect）。

8. 执行顺序与里程碑

  1. M0（本文档，B 阶段）✅
  2. A1：修 EXIT_1 → 跑 548 全量 → 带 Wilson 区间的可信 LUT（数据底座）
  3. A2：实现 M2(DeepSC 模拟,M2b) + M0/M5 上界 + 三信道配置 + latency/CBR 后处理
  4. A3：写 M4 规则版 LCB 贪心选择器
  5. A4：一次性跑组 1 标准四方 + 上界扫描（共用任务/信道，省算力）
  6. A5：出图 F1–F5 + 表 T1–T2
  7. B(后置)：RL unblock → 组 2 资源分配消融 → F6
关键省算力点：M1/M3/M4 共享同一批 Qwen 推理结果（只是选不同服务），一次全量扫描可同时产出 LUT + 组 1 多数曲线。

9. 预期叙事（论文 Story）

"现有 VQA 语义通信（GO-SG / MU-DeepSC）在单一固定传输策略下取得低 SNR 增益；但真实低空 A2G 信道 SNR 剧烈波动，固定策略要么浪费带宽（总传图）要么精度不足（总传 token）。我们提出语义效用驱动的自适应服务选择：用带 Wilson 下界的语义质量 LUT 在 cache/token/image/ROI 间逐任务择优，在传统整图发生悬崖式崩溃的低 SNR 区实现优雅降级，并由两时标 RL 在多流约束下优化资源分配——相同后端/信道/预算下，准确率全程贴近 Oracle 上界，传输代价远低于整图传输。"

  • Liu GO-SG, arXiv:2411.02452 — 场景图+bbox top-N；基线 DO-SG/Original-SG/Image-Transmission/Ground-Truth；Rayleigh，−2→8dB；+59% acc / −65% latency。

  • DeepJSCC 系列 — cliff-effect；基线 BPG+容量码 / JPEG+5G-LDPC；CBR 归一。
  • How to Evaluate SemCom, arXiv:2309.04891 — task 指标 + 语义指标，别只用 PSNR；CBR=k/n 归一。
