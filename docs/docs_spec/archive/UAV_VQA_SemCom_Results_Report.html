7. 诚实 caveat

  • M2 无编码模拟(JSCC-lite)在中低 SNR 不如离散 token（噪声图喂 Qwen 不稳），但低 SNR 无悬崖（−5dB 0.46 > naive 0.41）——帮我们讲透"数字 / 模拟 / 自适应"三方。
  • 基线定位（重要）：M2 是无编码模拟图传输(JSCC-lite)的经典对照，不是训练型 DeepSC；训练型语义编解码(DeepSC/DeepJSCC)与本文正交——本文是"服务层选择"范式，可与学习型 codec 叠加，故作相关工作引用而非正面竞品。论文措辞须避免"打赢 DeepSC"，改为"相对无编码模拟基线/传统数字传输"。
  • 计数任务整体偏难（连 Oracle 才 ~0.50），为 VQA 计数固有难度，论文如实说明。
  • M4 为规则版 LCB 贪心，已 train/test 切分排除过拟合；RL 资源分配（实验组 2）仍待做。
