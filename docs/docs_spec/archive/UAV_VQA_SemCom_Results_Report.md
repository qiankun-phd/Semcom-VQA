> held-out test set（按 image_id 20% 留出）· 6 方法 × 3 信道 × 6 SNR · VisDrone-DET 548 图 · Qwen2-VL-2B 统一后端

> 2026-06-29 · 配套 `UAV_VQA_SemCom_Comparison_Plan`


## 摘要

- **M4(我们的自适应服务选择）在三信道、每个 SNR 都超过所有固定基线**，贴近 Oracle 上界（差约 0.05）。

- **cliff-effect 成立**：naive 定速数字在 −5dB 断崖至 0.37–0.41；无编码模拟(JSCC-lite)与我们的自适应优雅降级。

- **机理**：计数任务 token 完胜（整图 0.28 vs token 0.46），存在性任务整图更优；M4 逐任务路由取两者之长。

- **效率**：M4 较传统整图省约 34% 字节，准确率反而更高。

- **基线定位**：M2 为无编码模拟图传输(JSCC-lite)的经典对照，非训练型 DeepSC；训练型语义编解码(DeepSC/DeepJSCC)与本文正交——本文是服务层选择范式，可叠加学习型 codec，故作相关工作引用而非正面竞品。

## 诚实 caveat

1. M2 无编码模拟(JSCC-lite)在中低 SNR 不如离散 token(噪声图喂 Qwen 不稳),但低 SNR 无悬崖(−5dB 0.46 > naive 0.41)——帮我们讲透'数字/模拟/自适应'三方。

2. 计数任务整体偏难(连 Oracle 才 ~0.50),为 VQA 计数固有难度。

3. M4 为规则版 LCB 贪心(已 train/test 切分,排除过拟合);RL 资源分配(实验组 2)仍待做。
