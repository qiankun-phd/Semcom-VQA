## 二、资源分配 RL 侧增量

- "语义压缩等级进 DRL 动作空间"**有先例**：arXiv 2601.01430（2026-01，UAV 数字语义通信）用 TQC（纯连续）联合优化 UAV 轨迹+语义压缩比+中继指派【引文】。
- 我方 v19 的增量在**组合**：离散证据路由头（cache/token/image，非连续压缩因子）+ 7 乘子风险感知拉格朗日 + 语义可行性安全投影（cache-override / deadline 降级）+ 5 条 Lyapunov 队列 + 双时间尺度移动头 + 实测 LUT-LCB 语义质量接口。单看每个组件都有文献，组合与"语义质量置信下界作为约束 RL 的接口"未见先例。
- 风险：组合式创新在 TWC/JSAC 审稿中常被压为"工程集成"——需要理论件（收敛/遗憾界或 Lyapunov 稳定性论证）撑腰。
